# powergreensclub.com

Static goodbye page for Power Greens Club, rebuilt from the 2017 saved-page version.
One self-contained HTML file plus two images. No build step, no JavaScript, no dependencies.

The original was a browser "save page as" dump that loaded jQuery, Bootstrap, Modernizr, a
supersized slider and an analytics script to display one sentence. Only `farm.jpg` and the
logo were worth keeping.

Deploy: commit and push. GitHub Pages serves the repository root.
